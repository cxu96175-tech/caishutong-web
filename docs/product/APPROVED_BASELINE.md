# 已确认基线

> 只有用户明确认可、确认、锁定或等价表达后，才能把内容写入本文件。临时方案和推测不得写入。

## 使用规则

- 本文件中的内容默认受保护。
- 用户未明确要求时，不修改、不重构、不重新设计、不更换组件、不改变交互。
- 如果确实需要突破基线，先说明影响并等待用户明确确认；得到确认后再更新本文件。
- 每条基线记录确认日期、确认范围和证据（对话、截图、版本或链接）。
