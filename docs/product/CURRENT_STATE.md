# 当前产品状态

## 产品范围

彩研通服务于中国体育彩票数字彩开奖查询与走势分析。当前产品包含开奖首页、彩种详情、综合数据、冷热分析、走势图、选号工具、方案及用户功能；不包含赛事资讯或赛事数据栏目。

## 当前用户路径

- 首页展示各数字彩种最近一次有效开奖；新一期未公布、来源暂时失败或写入失败时，保留上次有效结果并说明状态。
- 首页从服务端持久快照读取结果，浏览器缓存只用于首屏回退；用户刷新不应把缓存错误呈现为新数据。
- 历史记录、详情及走势图按需加载。
- 用户可从首页进入彩种详情、综合数据及相关走势/选号功能。

## 当前模块与数据

- 数字彩种开奖卡片、详情、综合数据、走势图、选号与图片导出沿用现有导航和视觉系统。
- 详情页“本期数据”仅展示与当前期号及开奖号码匹配的销量、奖池和一等奖中奖注数；排列3使用直选语义。缺失值显示“--”，不以其他期数据替代。
- 开奖记录按彩种、期号、日期及号码格式校验；快照仅在匹配同一期、同一组号码时补齐详情字段。
- 开奖追新由 GitHub Actions 调用不同环境的同步 Worker，在开奖时间范围内按彩种检查新期号。验证并保存新一期后，当天停止对该彩种继续抓取；调度和保存状态均需可追溯。
- 国家级数据源不可用时，数字体彩采集器可回退到对应省级体育彩票管理中心公开历史页面；记录经过字段、期号和号码校验。其他彩种保留各自现有来源。
- 现有首页、底部导航、详情、历史、走势图和开奖同步数据链路不应因产品范围调整而改变。

## 视觉与交互边界

- 保持现有导航层级、数字彩页面布局、品牌色、卡片样式及 Lucide 图标系统。
- 综合数据表格在窄屏中通过横向滚动完整查看；标签和文案保持不换行，并按内容确定表格宽度。
- 加载、空数据、错误、缓存回退和同步状态须明确，不展示猜测数据。

## 已知状态与验收

- 正式站现有彩票页面和开奖服务继续运行；最近已验证的部署及快照状态以 PROGRESS.md 中对应时间记录为准。
- 体彩公开历史页面的回退解析已实现；Cloudflare Worker 出网、Preview D1 同步及其余发布门槛按最新任务记录验收，不以本地构建代替线上验证。
- 本轮移除了赛事栏目及专属接口；发布后应确认首页不再展示赛事内容、赛事 API 不再提供数据，数字彩开奖 API 仍可用。
