## 3. 当前方案与数据源核验

首页开奖卡片后保留独立竞彩卡片，支持足球/篮球切换。百查 API Key 无法取得，改用大象比分公开 HTML：`/scores` 与 `/basketball` 为竞彩足球、竞彩篮球比分页，另有对应赛程页。来源站 robots.txt 允许公开页面抓取但禁止 `/api/`；只抓公开页面，按竞彩编号筛选，只返回赛事基础字段，赔率不持久化、不下发、不展示。
